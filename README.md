# Landing Page Project

## Description

This project is a responsive landing page created using HTML and CSS. The objective of the project is to demonstrate basic web development skills such as page layout design, sectioning, styling, and responsive design.

## Features

* Attractive header with navigation menu
* Hero section with welcome message and call-to-action button
* Feature cards displayed in columns
* Responsive layout using Flexbox
* Clean and modern user interface
* Footer section with copyright information

## Technologies Used

* HTML5
* CSS3

## Project Structure

```
Landing-Page/
│
├── index.html
├── style.css
└── README.md
```

## Learning Outcomes

Through this project, I learned:

* Structuring web pages using HTML
* Styling web pages using CSS
* Using Flexbox for layout design
* Managing spacing with margins and padding
* Creating responsive and visually appealing web pages
* Organizing webpage sections effectively

## How to Run

1. Download or clone the project files.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.
4. The landing page will load and display all sections.
